# Renata Cardoso — demonstração de website

Proposta comercial independente para apresentação. Não é o site oficial da profissional.

Site: https://lucarmeu-max.github.io/renata-cardoso-demo/

## Edição

O projeto React + Vite completo está em `source/`. Os dados estão centralizados em `source/src/config.js`. No diretório `source`, execute `npm install` e `npm run build`; copie o conteúdo de `dist/` para a raiz do repositório para atualizar o GitHub Pages.

O nome e os contatos foram fornecidos no briefing. Telefone e endereço aparecem no diretório público Solutudo; o e-mail aparece na listagem pública da Polícia Federal em nome de Renata Cardoso da Costa Pinto. Essas referências não substituem validação direta com a profissional. Dados podem estar desatualizados; os horários foram mantidos sem valor enquanto não confirmados. Formação, CRP, abordagem, modalidades e trajetória aguardam validação.

Referências de consulta:
- https://www.solutudo.com.br/empresas/go/formosa/psicologia?mais_buscadas=1&pagina=1
- https://www.gov.br/pf/pt-br/assuntos/armas/psicologos/psicologos-crediciados/distrito-federal

Não há formulários clínicos, analytics, mapas incorporados ou cookies próprios. Os botões de contato abrem serviços externos e não enviam mensagens automaticamente. A demonstração mantém aviso de site não oficial e instrução `noindex,nofollow`.
